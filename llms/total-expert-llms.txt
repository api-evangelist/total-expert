# Total Expert

> Total Expert is a fintech CRM and customer-engagement platform for banks, lenders, and mortgage companies. Its Public API is a REST/JSON surface at https://public.totalexpert.net/v1 secured with OAuth 2.0 (client credentials for admin-level integrations, authorization code for user-level access), covering contacts, leads, loans, insights, surveys, campaigns, users/teams, accounts, and webhooks.

Total Expert does not publish its own llms.txt; this file was generated by API Evangelist from the provider's public developer surface on 2026-07-21.

Key facts:
- Base URL: https://public.totalexpert.net/v1 (development/sandbox: https://public.vt.totalexpert.net)
- Auth: OAuth 2.0 — POST /v1/token with HTTP Basic client_id:client_secret; tokens are Bearer, valid 1 hour; refresh tokens valid up to 2 weeks; token endpoint limited to 2 requests/hour, so cache tokens.
- Rate limit: 1000 requests/minute per source IP (HTTP 429 when exceeded).
- Pagination: page[number] / page[size] (default 10); responses wrap results in objects + links (first/last/next/prev).
- Deduplication: POSTing a duplicate entity acts as a PATCH to the existing record.
- Webhooks: subscribe an HTTPS URL + secret to entity/verb actions via /v1/webhook-subscriptions.
