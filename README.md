# Total Expert

Total Expert is a fintech CRM and customer-engagement platform for banks, credit unions, lenders, and mortgage companies. Its Public API (https://public.totalexpert.net/v1) is documented via the [Total Expert developer portal](https://developer.totalexpert.net) and a public [Postman collection](https://documenter.getpostman.com/view/1929166/total-expert-public-api/6Z2RYyU), secured with OAuth 2.0, and covers contacts, leads, loans, insights, surveys, campaigns, users, teams, accounts, and webhook subscriptions.

This repository profiles Total Expert's public API surface for the API Evangelist network: an OpenAPI derived from the provider's Postman collection, plus authentication, OAuth scopes, conventions (pagination + deduplication), error catalog, rate limits, sandbox, webhooks, lifecycle, security, and agent-ready artifacts. See `apis.yml` for the index.
